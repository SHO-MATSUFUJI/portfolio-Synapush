# 0006. Cognitoの自己サインアップを無効化し、管理者作成のみとする

## ステータス

Accepted

## 決定

Cognitoユーザープールでは自己サインアップ（`allow_admin_create_user_only = true`）を無効化し、ユーザー作成は管理者がTerraform外（AWSコンソールやCLI）で個別に行う運用とする。MFAは設定しない（`mfa_configuration = "OFF"`）。

## 理由

このユーザープールは社内ログイン用（利用者は身内のみ）であり、不特定多数が自由にアカウントを作れる必要がない。自己サインアップを許可すると、招待していない第三者がアカウントを作成できてしまうリスクがあるため、管理者作成のみに絞った。

MFAはセキュリティ上望ましいが、ポートフォリオ用途で利用者数も少なく、SMS送信のコストや実装の複雑さに見合わないと判断しOFFとした。将来、実運用に近い形で見せたい場合はTOTPベースのMFAを追加する余地を残す。
