# （アプリ名：Synapush (シナプッシュ)

社内の公式ナレッジと個人のナレッジを、共に公開・共有できる社内向けアプリ。
Push操作で脳のシナプスを繋ぐ、社内の「知見の森」ナレッジベース

## 制作背景（Why）

製造業の現場管理・監督業務に携わる中で、リスクアセスメントの実務知見と、
育成用のガイドブック、2種類の性質が異なるナレッジを個人的に蓄積していた。

- 前者は法令・指針に基づく**公式相当**の知見
- 後者は自分の経験則に基づく**個人発**の知見だが、組織で使える完成度を持つ

この2つを同じ棚に並べて管理しようとしたとき、「読み取りは誰でも／編集は誰でも／
公開の可否だけは責任者が握る」という権限設計が必要だと気づいたのが出発点。

実データ（リスクアセスメント資料）を使ってこの権限モデルを検証しながら作った。

## 解決したい課題（What）

- 公式ナレッジと個人ナレッジが別々の場所に散らばっている（資料化の有無、脳内（暗黙知）、共有無し）
- 個人の知見を書いても、組織として使えるか誰も判断していない（放置される）
- 逆に、誰かが精査せず書いたものがそのまま「社内標準」として広まるのも怖い

→ **編集は開放、公開だけ承認を必須にする**ことで両方を防ぐ。

## 使用技術

| 分類 | 技術 |
|---|---|
| フロントエンド | React（S3 + CloudFront） |
| 認証 | Cognito（アプリ側ゲート方式） |
| ストレージ | S3 |
| 配信 | CloudFront |
| 自動公開 | GitHub Actions |
| インフラ管理（IaC） | Terraform |
| コンテンツ正本 | GitHub（Markdown + CODEOWNERS） |
| 実装補助 | Claude Code |

```
GitHub（Markdownの正本）
   │ マージするとGitHub Actionsが動く
   ↓
S3（Markdown本文・添付ファイルをそのままコピー）
   ↑
CloudFront ← React（起動時にS3のファイルを直接読み、一覧・検索を組み立てる）
                ↑
             Cognito（ログイン確認。未ログインはログイン画面のみ表示）
```

## 機能一覧

- [ ] ナレッジ一覧・詳細表示
- [ ] 検索（タイトル・タグ・本文）
- [ ] 社内ログイン（ゲストアカウントあり）
- [ ] 添付ファイル（Excel様式・PPTX等）のダウンロード

## 権限モデル

| ナレッジ種別 | 読み取り | 編集 | 公開承認者 |
|---|---|---|---|
| 公式 | 全社員 | GitHubアカウントを持つ役職者以上 | 各組織責任者（CODEOWNERS） |
| 個人 | 全社員 | GitHubアカウントを持つ役職者以上 | 本人（CODEOWNERS） |

- 編集は誰でも提案できる（Pull Request）。公開は承認（マージ）を経て初めて反映される
- 個人ナレッジが役職者以上に限定されるのは意図的な設計。ある程度の経験を経た知見の方が
  組織にとって価値が高いという判断による
- 承認者の割り当ては現時点では手動運用
