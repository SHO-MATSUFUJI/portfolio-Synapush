この章では、「危険」を分解して捉え、調べて把握する考え方を身につける。

## 2-1 災害はどのように発生するのか

災害は突然起きるのではなく、段階的なプロセスを経て発生する。

| 段階 | 英語 | 内容 | 例 |
|---|---|---|---|
| 危険源 | Hazard | エネルギーや有害物質など、災害の根本原因 | 回転する砥石 |
| 危険状態 | Hazardous Situation | 人が危険源にさらされている状態 | 砥石の近くで作業中 |
| 危険事象 | Hazardous Event | 危険状態から災害につながる出来事 | 砥石が破損し飛散 |
| 災害 | Harm | 人に被害が発生した結果 | 破片が顔面に当たり負傷 |

RAは「災害が起きてから対処」ではなく、この連鎖を事前に断ち切ることを目的としている。

## 2-2 危険源・危険事象・リスクの違い

この3つの概念を混同すると、正確なリスク評価ができない。

| 概念 | 内容 | 例 |
|---|---|---|
| 危険源（ハザード） | 災害を引き起こす潜在的な根源。モノ・物質・環境が持つ固有のエネルギーや有害性 | 回転体、高所、化学物質、高温面、鋭利な刃物 |
| 危険事象 | 危険源が人に害を及ぼす出来事。「～なので→～して→～になる」で書く（2-5参照） | 砥石カバーが外れ、破片が飛散して作業者に当たる |
| リスク | 危険事象が起きる可能性と重大性の組合せ。数値化して比較可能にする | リスク点数12点 → リスクレベル「中リスク」 |

「危険源」と「危険事象」を分けて書くことが、正確な評価の第一歩になる。

## 2-3 日本と欧米の考え方の違い

| | 日本型の安全管理（従来） | 欧米型のリスクアセスメント |
|---|---|---|
| 捉え方 | 「危険」を一括りにして扱う | 危険源・危険事象・リスクを分解 |
| 調査方法 | 経験と勘に頼った安全対策 | 体系的・網羅的に危険を調査 |
| 対策 | 「気をつけろ」が最終手段になりがち | 設備や仕組みで防ぐことを優先 |
| 依存先 | 人の注意力に依存する管理 | 人に依存しない安全を設計 |

日本型は個人の意識に依存するため、組織として弱くなる。欧米型は仕組みで守るため、組織として強くなる。

## 2-4 「見つける」から「調べる」への転換

リスクアセスメント最大の思想転換がここにある。

| | 従来：気づき型 | RA：調査型 |
|---|---|---|
| やり方 | 「気がついた人が報告する」 | 「全作業を対象に体系的に調べる」 |
| 特徴 | ベテランは見つけられるが新人は見つけられない | 手順・設備・環境を網羅的にチェック |
| 結果 | 人によって見つかるリスクが変わる | 誰がやっても同じリスクが抽出される |
| 位置づけ | 個人の気づきに依存 | 組織の仕組みとしてリスクを管理 |

「たまたま気づいた危険」ではなく、「調べて把握した危険」を扱うのがRAの特徴である。この意識の転換が、リスクアセスメントの出発点になる。

## 2-5 危険事象の正しい書き方

### 基本の型

「～なので（物・危険源が何か）→ ～して（人・どう接触するか）→ ～になる（結果・どんな被害か）」で書く。

- **良い例**：砥石カバーの固定ボルトが緩んでいるため、研削中に砥石が破損・飛散し、作業者の顔面に当たり裂傷を負う
- **悪い例**：砥石が危ない → 何が・どう・どうなるかが不明で、評価も対策もできない

### 具体例①：砥石研磨作業

- 不正確な記述：「砥石で怪我をする」（何が原因か、どう怪我するか、どの程度か、すべて不明）
- 正しい記述：
  - ～なので（物）：砥石カバーの固定ボルトが緩んでいるため
  - ～して（人）：研削中に砥石が破損・飛散し、作業者の顔面に当たり
  - ～になる（結果）：裂傷を負う（休業災害レベル）

### 具体例②：台車運搬作業

- 不正確な記述：「台車で運搬中に腰を痛める」（台車のどの特性が原因か、どの状況で発生するかが不明）
- 正しい記述：
  - ～なので（物）：25kgの製品を載せた台車の車輪が段差で引っかかるため
  - ～して（人）：作業者が無理な姿勢で押し込もうとして
  - ～になる（結果）：腰部に過度な負荷がかかり腰痛を発症する

## 2-6 危険性・有害性の特定キーワード

危険源を洗い出すときの手がかりを、以下に示す。

| 分類 | キーワード例 | 関連する作業 |
|---|---|---|
| 機械的危険源 | 回転体、挟まれ、巻き込み、切断、衝突、落下 | 旋盤、プレス、コンベア、クレーン作業 |
| 電気的危険源 | 感電、漏電、アーク、スパーク、静電気 | 配電盤作業、溶接、電気設備点検 |
| 熱的危険源 | 高温面、火災、爆発、凍傷、熱中症 | 炉作業、溶接、屋外作業 |
| 化学的危険源 | 有毒ガス、粉じん、腐食性液体、発がん性 | 塗装、洗浄、薬品取扱い |
| 人間工学的危険源 | 重量物、反復動作、不自然な姿勢、振動 | 運搬、組立、研磨作業 |

このリストは一例である。対象とする作業に合わせて、該当する危険源を抜け漏れなく洗い出す。

## 2-7 対象範囲とグレーゾーンの判断

### 対象範囲の根拠

安衛法第28条の2「…作業行動その他業務に起因する危険性又は有害性等を調査…」

**対象となるもの（業務に起因）**
- 機械・設備の使用に伴う危険
- 化学物質の取り扱いに伴う危険
- 作業方法・作業環境に伴う危険
- 作業が原因の火災・爆発、設備の固定不足等

**対象外となるもの**
- 地震・台風などの自然災害（→防災訓練・BCP）
- 一般的な建物火災（→消防法の防火管理）

### グレーゾーンの判断フロー

「業務に起因する」の線引きに迷ったときは、次の順で考える。

1. その危険は「業務」に起因するか？　YES → RA対象／NO → 次へ
2. 作業手順・設備・環境のいずれかに関係するか？　YES → RA対象／NO → 次へ
3. 会社として管理可能なリスクか？　YES → RA対象／NO → 対象外

**判断に迷う場合は「対象に含める」を原則とする。** 対象外とする場合は、その理由を記録に残す。

### 判断の具体例

| ケース | 判定 | 判断理由・改善の方向性 |
|---|---|---|
| 溶接火花が可燃物に着火 | ○ 対象 | 「溶接作業に伴う」火災リスク。可燃物撤去・防炎シート使用で改善可能 |
| 研削液がコンセントにかかり発火 | ○ 対象 | 「研削作業に伴う」火災リスク。防水コンセント・飛散防止で改善可能 |
| 研削盤が固定されず地震時に転倒 | ○ 対象 | 「機械の固定不足」という作業環境の問題。設置方法（アンカー固定等）で改善可能 |
| 事務室の一般コンセントの発火 | △ 判断が分かれる | 作業と直接関係ない火災。防火管理（定期清掃・点検）で対応 |
| 大地震で建物が倒壊 | × 対象外 | 耐震性は建築基準法の領域。作業改善では防げない |

○＝対象、△＝防火管理等で対応、×＝対象外。
