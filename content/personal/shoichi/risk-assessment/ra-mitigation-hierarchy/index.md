## 要点

対策は必ず **★ → ① → ② → ③ → ④** の順に検討する。上位の対策ほど効果が高く、人に依存しない。

| 順位 | 分類 | 目的 | 代表例 |
|---|---|---|---|
| ★ | 法令遵守 | 法令に定めがあるものは必ず実施 | 高さ2m以上の作業床に手すり（安衛則519条） |
| ① | 本質的対策 | 危険源そのものを除去・低減 | 有害物質を無害な物質に代替、高所作業を地上作業に変更 |
| ② | 工学的対策 | 設備の仕組みで人を守る | インターロック、安全柵、光カーテン、局所排気装置 |
| ③ | 管理的対策 | 手順・教育・ルールで守る | 作業手順書、安全教育、警告標識、作業許可制度 |
| ④ | 個人用保護具 | 残留リスクに対する最後の手段 | 保護メガネ、防じんマスク、耐切創手袋 |

「いきなり④保護具」はNG。

## 詳細

### ★ 法令遵守はリスクレベルと無関係

法令で定められた対策は、RAの評価結果に関わらず必ず実施する。**「点数が低いから不要」にはならない。**

主な規定例：

- 2m以上の高所作業 → 手すり・安全帯使用義務（安衛則518〜519条）
- 回転機械の危険部分 → 覆い・囲い等の設置義務（安衛則101条）
- プレス機械 → 安全装置の設置義務（安衛則131条）
- 化学物質の取扱い → 局所排気・保護具の義務（特化則・有機則）

### ①②の共通点：人が「気をつける」必要がない

本質的対策と工学的対策は、**人の行動に依存しない**点で共通する。設備や仕組みが自動的に安全を確保する。

| ① 本質的対策 | ② 工学的対策 |
|---|---|
| 有害物質を低毒性のものに代替 | インターロック（扉開→機械停止） |
| 高所作業を地上作業に変更 | 安全柵・光カーテンの設置 |
| 鋭利な角をR加工で除去 | 局所排気装置の設置 |
| 重量物を軽量化・分割 | 非常停止ボタンの適正配置 |

### ③ 管理的対策の限界

管理的対策 ＝ **人に依存する対策**。以下の限界を持つ。

- ルールを知らない人には効果ゼロ
- 疲労・焦りで守られないことがある
- 形骸化しやすい（慣れ・省略）
- 人が変わると効果が変わる

ただし「これだけでは不十分」であって「やらなくていい」ではない。上位対策を検討した上で、**補完として**活用する。

### ④ 保護具は最後の手段

| NG：いきなり保護具 | OK：順番を守る |
|---|---|
| 「粉じんが出る → マスク着用」 | ① 発生源の密閉化を検討 |
| 他の対策を検討せず保護具だけで解決しようとする | ② 局所排気装置を設置 |
| | ③ 作業手順で接触時間を短縮 |
| | ④ 残留リスクに対しマスク着用 |

### 対策の本質による分類

優先順位とは別軸で、対策の作用を5つに分類できる。

| 分類 | 目的 | キーワード | 具体例 |
|---|---|---|---|
| 除去 | 危険源をなくす | 廃止・代替・変更 | 有害物質を無害な物質に代替 |
| 隔離 | 人と危険源を離す | 囲い・カバー・遮蔽 | 回転体にカバーを設置し接触不可にする |
| 停止（工学） | 危険時に自動停止 | インターロック・非常停止 | カバー開放時に機械が自動停止 |
| 低減（管理） | ばく露・接触を減らす | 手順・教育・ルール・標識 | 作業手順書の整備と定期教育 |
| 保護 | 被害を軽減する | 保護具・保護衣・安全靴 | 防じんマスク・保護メガネの着用 |

### 精神論では災害は防げない

「注意しろ」「気をつけろ」が対策にならない理由：

- 人は必ずミスをする（ヒューマンエラー）
- 注意力には限界がある（疲労・慣れ）
- 新人や異動者は危険を知らない
- 「気をつけて」は対策ではない

だからこそ必要なこと：設備投資による本質的な安全確保／人に依存しない仕組みづくり／経営判断としてのリスク低減／対策の優先順位を守る文化。

## 比喩

危険源（ライオン）を **なくす → 囲う → 管理する → 身を守る** の順で対策する。鎧（保護具）は最後の手段。

## 許容判断との接続

同じ点数でも、**どの階層の対策を経てその点数になったか**で許容可否が変わる。詳細は `ra-acceptance-judgement` 参照。

- ケースA：10点。本質的対策＋工学的対策を実施済み → 上位対策を尽くした上での10点 → **許容可**
- ケースB：10点。管理的対策のみ → 上位対策を未検討 → **許容不可**
