## 基本の型

「～なので（物・危険源が何か）→～して（人・どう接触するか）→～になる（結果・どんな被害か）」で書く。

**良い例**：砥石カバーの固定ボルトが緩んでいるため、研削中に砥石が破損・飛散し、作業者の顔面に当たり裂傷を負う

**悪い例**：砥石が危ない → 何が・どう・どうなるかが不明。これでは評価も対策もできない

## 具体例①：砥石研磨作業

- 不正確な記述：「砥石で怪我をする」（何が原因か、どう怪我するか、どの程度か、すべて不明）
- 正しい記述：
  - ～なので（物）：砥石カバーの固定ボルトが緩んでいるため
  - ～して（人）：研削中に砥石が破損・飛散し、作業者の顔面に当たり
  - ～になる（結果）：裂傷を負う（休業災害レベル）

## 具体例②：台車運搬作業

- 不正確な記述：「台車で運搬中に腰を痛める」（台車のどの特性が原因か、どの状況で発生するかが不明）
- 正しい記述：
  - ～なので（物）：25kgの製品を載せた台車の車輪が段差で引っかかるため
  - ～して（人）：作業者が無理な姿勢で押し込もうとして
  - ～になる（結果）：腰部に過度な負荷がかかり腰痛を発症する

## 危険性・有害性の特定キーワード（洗い出しの手がかり）

| 分類 | キーワード例 | 関連する作業 |
|---|---|---|
| 機械的危険源 | 回転体、挟まれ、巻き込み、切断、衝突、落下 | 旋盤、プレス、コンベア、クレーン作業 |
| 電気的危険源 | 感電、漏電、アーク、スパーク、静電気 | 配電盤作業、溶接、電気設備点検 |
| 熱的危険源 | 高温面、火災、爆発、凍傷、熱中症 | 炉作業、溶接、屋外作業 |
| 化学的危険源 | 有毒ガス、粉じん、腐食性液体、発がん性 | 塗装、洗浄、薬品取扱い |
| 人間工学的危険源 | 重量物、反復動作、不自然な姿勢、振動 | 運搬、組立、研磨作業 |

このリストは例示。対象とする作業に合わせて、該当する危険源を抜け漏れなく洗い出す。
