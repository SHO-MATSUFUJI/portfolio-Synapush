リスクアセスメント記録シートの列構成。機械設備用を基本とし、一般作業用・化学物質用も基本構成は同じ（軸の名称のみ異なる）。

## ヘッダー部

部門/作業場所、対象危険源、現状評価日、現状評価者、対策後評価日、対策後評価者、承認欄

## 記録テーブルの列

| 列 | 内容 |
|---|---|
| No | 通し番号 |
| 業務内容 | 対象作業 |
| 作業区分 | 定常／非定常 |
| 危険性又は有害性の特定 | 「～なので→～して→～になる」で記述（`ra-hazard-event-description`参照） |
| 現状リスク評価 | ハード(1-5)／ソフト(1-5)／頻度(1-5)／程度(1-5)／合計(20点) |
| リスクレベル | 合計点から判定（`ra-risk-level-table`参照） |
| 優先順位 | 対策の優先順位（★・①〜④、`ra-mitigation-hierarchy`参照） |
| リスク低減措置 | ①本質的対策／②工学的対策／③管理的対策／④保護具の4欄。担当者・対策予定日・対策実施日も記載 |
| 対策後リスク評価 | 対策実施後の再評価。ハード／ソフト／頻度／程度／合計 |
| 対策後レベル | 対策後の合計点から再判定 |
| 許容判定 | 許容／許容不可 |
| 残留リスク | 有／無 |
| 管理項目記入欄 | 残留リスクの内容・暫定管理措置・恒久対策の計画（3点セット、`ra-residual-risk`参照） |
