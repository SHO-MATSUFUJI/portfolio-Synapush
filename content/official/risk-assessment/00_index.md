リスクアセスメント（以下RA）について個人で体系化してきた知見をまとめたもの。

## 一覧

### 思想
- `ra-hazard-decomposition` 危険源→危険状態→危険事象→災害
- `ra-investigate-not-notice` 「見つける」から「調べる」への転換
- `ra-hazard-event-description` 危険事象の書き方
- `ra-scope` RAの対象範囲
- `ra-mitigation-hierarchy` 対策の優先順位
- `ra-residual-risk` 残留リスクの考え方
- `ra-acceptance-judgement` 許容判断／許容と低リスクの違い
- `ra-pdca` 再評価タイミングとPDCA

### 評価基準
- `ra-eval-anchor-machine` 機械設備RA 4軸アンカー
- `ra-eval-anchor-general` 一般作業RA 4軸アンカー
- `ra-eval-anchor-chemical` 化学物質RA 2軸アンカー
- `ra-risk-level-table` リスクレベル判定基準（3体系）
- `ra-severity-principle` 程度の共通原則
- `ra-frequency-principle` 頻度の共通原則

### 様式と記入例
- `ra-record-columns` 記録シートの列定義
- `ra-record-sample-machine` 記入例：旋盤チャック巻き込まれ

### 根拠と出典
- `ra-legal-basis` 法的根拠
- `ra-design-rationale` 評価手法の設計根拠と自己裁量範囲

### 事例集
- `ra-case-coolant-eye` 研削液が目に入る
- `ra-case-fire-explosion` 火災・爆発リスク
- `ra-case-coolant-outlet` 研削液がコンセントで発火
- `ra-case-scope-judgement` 対象範囲の判断事例

## 用語

| 用語 | 定義 |
|---|---|
| 危険源（ハザード） | 災害を引き起こす潜在的な根源。モノ・物質・環境が持つ固有のエネルギーや有害性 |
| 危険状態 | 人が危険源にさらされている状態 |
| 危険事象 | 危険状態から災害につながる出来事 |
| 災害 | 人に被害が発生した結果 |
| リスク | 危険事象が起きる可能性と重大性の組合せ |
| 残留リスク | 対策実施後も完全に除去できずに残るリスク |
| 許容 | 実施可能な対策を講じた上で、残留リスクを管理する前提で受け入れる判断。「安全である」「低リスクである」とは別概念 |
| 本質的対策 | 危険源そのものを除去・低減する対策 |
| 工学的対策 | 設備の仕組みで人を守る対策 |
| 管理的対策 | 手順・教育・ルールなど人に依存する対策 |
